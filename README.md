# 📸 מערכת מספור תמונות חתונה

## 🎯 מה זה?

מערכת זו מאפשרת לצלמי חתונה:
1. **להעלות** PDF עם תמונות
2. **להוסיף מספרים** אוטומטיים לכל תמונה
3. **לאשר** את ה-PDF
4. **לשתף** עם הזוג בקישור ייחודי

הזוג יכול להוסיף הערות לכל תמונה, והצלם רואה את ההערות באותו קישור.

---

## 🚀 איך להשתמש?

### שלב 1️⃣: טעינת ה-PDF
1. פתח את האתר: https://weddingalbumnumberig.onrender.com
2. בחר קובץ PDF עם תמונות
   - גרור את הקובץ לתוך הריבוע
   - או לחץ על "בחר קובץ PDF"
3. אחרי שבחרת - תראה את שם הקובץ מוצג ✅

### שלב 2️⃣: הוספת המספרים
1. לחץ על כפתור **"✨ הוסף מספרים והורד PDF ממוספר"**
2. המערכת תעבד את ה-PDF (ראה הודעה: "⏳ עיבוד...")
3. ה-PDF יורד למחשב שלך
4. בדוק את התמונות - אם המספרים בדיוק במקום - סיימנו! ✅

### שלב 3️⃣: אישור ה-PDF
> **עדיין בעבודה** - קרוב מאוד!

כשתסיים לבדוק את המספרים:
1. לחץ על כפתור **"✅ PDF מאושר"**
2. המערכת תיצור קוד ייחודי (משהו כמו: `a1b2c3d4e5f6`)
3. תקבל **שני קישורים**:
   - **קישור לזוג**: שלח את זה לזוג להערות
   - **קישור לצלם**: שלח לעצמך להציג הערות

### שלב 4️⃣: שתיפה עם הזוג
1. שלח לזוג את **קישור הזוג**
2. הזוג נכנס, רואה את כל התמונות עם מספרים
3. הזוג כותב הערות לתמונות שמעניינות אותו
4. הערות נשמרות אוטומטית

### שלב 5️⃣: צפייה בהערות
1. אתה נכנס לאותו קישור (או ל**קישור הצלם**)
2. אתה רואה את הערות הזוג על כל תמונה
3. גם אתה יכול להוסיף הערות

## 📋 טיפים וטריקים

### 🎨 בחירת עיצוב
כרגע **עיצוב 2** פעיל. 
- המספרים ממוצבים בדיוק לתמונות שלך
- אם תוכל לאסוף קואורדינאטות עבור עיצוב 1 ו-3 - נוכל להוסיף אותם

### 💾 שמירת הקודים
**חשמל!** שמור את הקודים:
```
קוד הזוג: abc123xyz
קישור הזוג: https://wedding-review.com/couple/abc123xyz
קישור צלם: https://wedding-review.com/photographer/abc123xyz
```

### ⏰ תוקף
- כל אלבום נשמר **שנה שלמה**
- אחרי שנה - הקובץ מוחק אוטומטית
- אם צריך יותר זמן - צור אלבום חדש

### ❌ בעיות נפוצות

**"המספרים לא בדיוק במקום"**
- זה בעיה של קואורדינאטות
- צור issue בGitHub וזה יתקן

**"PDF לא מטען"**
- נסה PDF קטן יותר (מתחת ל-50MB)
- ודא שה-PDF קריא

**"האתר לא עובד"**
- Render free tier נרדם אחרי 15 דקות
- רענן את הדף וחכה דקה
